# Dirección de diseño — Polaris en estilo editorial crepuscular

## Adaptación

El documento recibido funciona como una **dirección visual**, no como un cambio de nombre ni de producto. Polaris Web Studio conserva su logotipo, su contenido comercial, sus rutas y su acción principal: planificar un proyecto. La nueva landing adopta una voz de revista tecnológica tranquila: un único hero atmosférico, seguido de un lienzo claro con lectura editorial y control visual mínimo.

| Rol | Decisión para Polaris |
|---|---|
| Hero | Gradiente de atardecer azul, violeta, malva y coral; el texto se lee sobre una superficie blanca para conservar contraste. |
| Firma visual | Una sola maqueta blanca con una muestra real de portafolio; no se añaden fotografías de stock ni ilustraciones. |
| Tipografía | Playfair Display como sustituto serif de display; Inter para navegación, cuerpo y controles. Cabinet Grotesk y Satoshi no se eliminan del sistema global. |
| Acción | `#007aff` se reserva para los botones principales, enlaces y estados interactivos. |
| Superficies | `#f7f7f7` como lienzo, blanco como lectura y halos de 5 px para elevar sin sombras pesadas. |
| Estructura | Hero inmersivo y, debajo, secuencia editorial de una columna. Los servicios, planes y productos se presentan como entradas separadas por líneas, no como cuadrículas de tarjetas. |

> La dirección evita copiar el nombre, el icono o el contenido de la referencia. El resultado debe sentirse como **Polaris Web Studio**, con una atmósfera de atardecer y una presentación editorial más cálida.
