# Upgrade integral de landing — Polaris Web Studio

## Diagnóstico de la referencia indicada

La variante crepuscular funciona por tres decisiones: un hero con una única imagen de portafolio, una superficie de lectura muy clara y un ritmo editorial limpio. Aun así, su parte media repite bloques de texto y no muestra suficiente evidencia visual de la amplitud real de Polaris: casos, productos, método y capacidades se leen más de lo que se experimentan.

## Dirección de upgrade

La landing conservará el hero editorial como punto de entrada, pero evolucionará a un **recorrido de estudio digital**. Cada sección tendrá una sola intención, un activo visual dominante y copy breve. La experiencia irá de la promesa a la prueba: visión → capacidades → casos → recorrido de trabajo → ecosistema → inversión → conversación.

| Momento | Activo dominante | Trabajo para el usuario |
|---|---|---|
| Hero | Maqueta editorial de un proyecto real | Entender qué hace Polaris y dar el siguiente paso. |
| Señal de valor | Mapa visual de estrategia, diseño y tecnología | Ver cómo se conectan las capacidades sin leer un manifiesto largo. |
| Casos | Galería de pantallas reales del portafolio | Comprobar el nivel y la variedad del trabajo. |
| Método | Recorrido visual de tres etapas | Entender qué esperar al iniciar. |
| Ecosistema | Tres productos como piezas conectadas | Distinguir web, Local Lift y Polaris Flow. |
| Inversión | Paquetes compactos y comparables | Elegir un punto de partida sin ruido. |

## Activos

El upgrade reutilizará las capturas y maquetas reales ya incluidas en el repositorio. Se crearán componentes vectoriales propios para el mapa de capacidades y el recorrido operativo, evitando imágenes de stock o contenido ajeno. Por tanto, **no necesitas crear activos en otra herramienta por ahora**.

> La regla de contenido será: cada bloque debe decir menos y mostrar más. Los textos secundarios pasan a ser leyendas cortas junto a maquetas, diagramas o galerías reales.
